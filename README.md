
# Contact Management System

A desktop-based Contact Management System built with Python and Tkinter.

## Features
- Add new contacts
- View all saved contacts in a table
- Search by name, phone number, or email
- Update selected contact details
- Delete contacts with confirmation
- JSON-based persistent storage
- Basic phone validation and duplicate prevention
- Graphical desktop interface

## Technologies Used
- Python 3
- Tkinter and ttk
- JSON File Handling

## Requirements
- Python 3 installed
- Tkinter available with Python

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python main.py
```

On Windows, you can also run `py main.py`.

## Data Storage
Contact records are stored locally in `contacts.json`.
The file is created automatically after adding the first contact.
